# Project: Fair Spin

> Якщо `openspec init` створить власний `project.md` — злити вміст, не затирати.

## What

Веб-застосунок для випадкового вибору елемента зі списку. Гравець **фізично впливає** на результат: крутить колесо ривком, тягне ричаг, зрізає колоду й обирає карту.

Деплой: GitHub Pages, `https://maslovss.github.io/fair-spin/`
Аудиторія: підлітки та їхні батьки. Головний пристрій — Android-телефон.

## Product principle: Чесний Стіл

- Усе, що лежить на столі, реально може випасти.
- Усе, що випасти не може, зі столу зникає.
- Гравець — учасник, а не глядач.

Це не гасло, а лінійка. Будь-яка пропозиція перевіряється питанням «це чесний стіл?». Повний опис механіки та журнал відкинутих рішень з причинами — `docs/mechanics.md`. **Читати перед будь-якою зміною поведінки.**

Найважливіший наслідок: **результат не обчислюється наперед**. Анімація не «доїжджає» до заздалегідь відомого переможця — переможець визначається тим, де фізика зупинила предмет. Будь-яка реалізація, що спершу викликає RNG для вибору переможця, а потім анімує до нього, є порушенням і не приймається.

## Tech stack

| Шар | Рішення |
|---|---|
| Мова | TypeScript, strict |
| Збірка | Vite |
| UI | Ванільний DOM, без фреймворка |
| Колесо | SVG |
| Котушка, карти | DOM + CSS transforms |
| Звук | Web Audio API, синтез, без файлів |
| Сховище | localStorage, один ключ, версіонована схема |
| Офлайн | PWA, vite-plugin-pwa, cache-first |
| Тести | Vitest (фізика, сховище, чисті редюсери) |
| CI | GitHub Actions → GitHub Pages |

**Чому без фреймворка:** застосунок — це три імперативні анімації над трьома плоскими структурами стану. Реактивний рендер тут лише заважає циклу анімації.

## Conventions

- Модулі — ES-модулі, один модуль = одна відповідальність.
- Ніяких залежностей рантайму понад vite-plugin-pwa. Кожна нова залежність потребує обґрунтування в `design.md`.
- Чиста логіка (фізика, редюсери стану, міграції) не торкається DOM і покривається тестами.
- DOM-код не містить бізнес-правил.
- Іменування: `camelCase` для змінних, `PascalCase` для типів, `kebab-case` для файлів.
- Коміти: `type(scope): subject`, один рядок.
- Тексти інтерфейсу — тільки через i18n-ключі. Літералів українською чи англійською в коді немає.

## Hard constraints

- **base path** — усі шляхи відносні, `base: '/fair-spin/'`. Абсолютних `/...` не існує ніде: ні в коді, ні в CSS, ні в маніфесті.
- **Жодних мережевих запитів** у рантаймі. Ні аналітики, ні шрифтів з CDN, ні телеметрії. Наслідок: не потрібні cookie-банер і політика приватності.
- **Фіксований крок фізики** 1/120 с з акумулятором. Прив'язка до частоти кадрів робить результат залежним від пристрою, а це вже питання чесності.
- **`crypto.getRandomValues`** — лише для розкладки (порядок секторів, порядок колоди). Результат кидка дає фізика, не RNG.
- **Мови** — `uk`, `en`. Російська не додається.

## Commands

```bash
npm run dev          # локальний сервер
npm run build        # збірка в dist/
npm run preview      # перевірка збірки, включно з PWA
npm run typecheck    # tsc --noEmit
npm run test         # vitest
```

`npm run typecheck && npm run test` має проходити перед позначенням будь-якої задачі виконаною.
