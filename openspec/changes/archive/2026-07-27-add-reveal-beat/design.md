# Design: Reveal Beat

## Decision: Такт живе в ядрі, не в столах

Пауза потрібна всім столам однаково, а таймінг і блокування вводу — річ, яку легко реалізувати трьома різними способами в трьох файлах і отримати три різні відчуття.

Тому такт належить спільному життєвому циклу столу, а стіл лише отримує команду підсвітити елемент і команду перебудуватись. Стіл не вирішує, скільки триває пауза, і не запускає перебудову самостійно.

## State Machine

```
idle ──ввід──▶ resolving ──зупинка──▶ settling ──▶ revealing ──▶ applying ──▶ idle
                                                        │
                                                   дотик │ пропуск
                                                        ▼
                                                    applying
```

| Стан | Ввід | Що відбувається |
|---|---|---|
| `idle` | приймається | стіл у спокої |
| `resolving` | ігнорується | фізика, дотик не впливає |
| `settling` | ігнорується | доводка показу, лише для котушки |
| `revealing` | лише пропуск | підсвітка, стіл нерухомий |
| `applying` | ігнорується | вибуття, перебудова, політ у цвинтар |

Результат обчислюється **один раз** на переході `resolving → settling` і далі передається як значення. У станах `settling`, `revealing` і `applying` зсув та кут читаються лише для показу.

Це головна структурна гарантія: якщо в коді після зупинки є друге читання позиції для визначення переможця, це помилка навіть тоді, коли значення збігається.

## Timing

```ts
const REVEAL_HOLD_MS = 1000
```

Одна константа на всі столи. Пропуск дотиком завершує такт достроково.

Зменшення анімації прибирає пульсацію, але **не прибирає паузу**: пауза є інформаційною, а не декоративною, і потрібна саме тим, кому важко відстежувати швидкі зміни.

## Highlight

Підсвітка — властивість столу, спільним лишається лише її вмикання й вимикання.

| Стіл | Вигляд |
|---|---|
| Колесо | сектор яскравішає, тонке кільце по краю |
| Слот, стрічка | рамка потовщується, комірка яскравішає |
| Карти | перевернута карта злегка піднімається |

Пульсація — один м'який цикл за час такту, не безкінечний блимаючий цикл.

## Cemetery Transition

Перехід у цвинтар починається лише в `applying`. Політ елемента до списку робить зв'язок наочним і водночас маскує перебудову столу, яка відбувається одночасно.

Порядок усередині `applying`: старт польоту → перебудова складу столу → нові позиції. Для колеса це означає, що сектори з'їжджаються вже після того, як елемент видимо залишив коло.

## Input Locking

Блокування вводу поширюється на всі шляхи запуску: жест, ричаг, флік, дію «Спробувати удачу» і майбутнє трясіння. Реалізується єдиною перевіркою стану на вході, а не окремими прапорцями в кожному столі.

Дотик у `revealing` не є перериванням руху й не суперечить забороні переривання котушки: предмет уже зупинився, результат уже обчислено, пропускається лише показ.

## Testing

Чиста логіка, без DOM:

- послідовність станів для обох режимів;
- результат, обчислений при зупинці, збігається з тим, що потрапив у цвинтар;
- ввід у `resolving`, `settling`, `revealing` і `applying` не запускає новий кидок;
- пропуск дотиком скорочує такт, але не змінює результат;
- при зменшенні анімації пауза зберігається.
