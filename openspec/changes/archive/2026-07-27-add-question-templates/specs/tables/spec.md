# Delta for Tables

## ADDED Requirements

### Requirement: Question Must Be Posed Before Play

Поки шаблон не доповнено й не підтверджено, стіл MUST бути неактивним. Блокування MUST поширюватися на **всі** шляхи запуску без винятку: жест на будь-якому столі, ричаг, флік, вибір карти, дія «Спробувати удачу» та будь-який майбутній спосіб запуску.

Блокування MUST реалізовуватись єдиною перевіркою стану на вході, а не окремими прапорцями в кожному столі.

Користувачеві MUST бути показано, чого бракує, — так само, як на столі карт при недоступній роздачі.

Підтвердження порожнього поля знімає блокування: заглушка є повноцінним запитанням.

#### Scenario: Table is inactive until the question is posed

- GIVEN відкрито шаблон, доповнення не підтверджено
- WHEN користувач намагається зробити кидок
- THEN нічого не відбувається
- AND показано, що спершу треба поставити запитання

#### Scenario: Try your luck is blocked too

- GIVEN доповнення не підтверджено
- WHEN користувач обирає «Спробувати удачу»
- THEN розіграш не запускається

#### Scenario: Cards are blocked too

- GIVEN доповнення не підтверджено й активний стіл карт
- WHEN користувач намагається зрізати або роздати
- THEN дія недоступна

#### Scenario: Placeholder unlocks the table

- GIVEN користувач підтвердив порожнє поле
- WHEN підставлено заглушку
- THEN стіл активний

#### Scenario: Completed questions are never blocked

- GIVEN запитання без трикрапки в назві
- WHEN користувач його відкриває
- THEN стіл активний одразу
