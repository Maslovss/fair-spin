# Delta for Platform

## MODIFIED Requirements

### Requirement: Schema Versioning

Збережені дані SHALL містити номер версії схеми, а застосунок MUST мати функцію міграції, що приводить старіші версії до поточної. Міграція MUST виконуватись без втрати незавершених раундів і без втрати користувацьких пресетів.

#### Scenario: Unknown or damaged data

- GIVEN у сховищі лежать пошкоджені або нерозпізнані дані
- WHEN застосунок стартує
- THEN він запускається на чистому стані замість аварії

#### Scenario: Migrating game mode from preset to state

- GIVEN сховище версії 1, де прапорець вибування зберігався в пресеті
- WHEN застосунок стартує
- THEN значення прапорця перенесено до стану відповідного пресету
- AND поле видалено з пресету
- AND незавершені раунди збережено разом із цвинтарями
- AND версію схеми піднято до 2

#### Scenario: Migration runs once

- GIVEN сховище вже мігровано до версії 2
- WHEN застосунок стартує ще раз
- THEN дані лишаються незмінними
