# Delta for Presets

## MODIFIED Requirements

### Requirement: Preset Structure

Пресет SHALL містити назву та впорядкований список елементів. Елемент є рядком тексту, що MAY містити unicode-емодзі; окремих полів кольору, іконки чи ваги не існує.

Пресет MUST NOT містити прапорця вибування. Режим гри є властивістю стану раунду, а не списку.

#### Scenario: Valid preset

- GIVEN користувач створює пресет із назвою та трьома елементами
- WHEN він зберігає пресет
- THEN пресет збережено
- AND він доступний у списку пресетів

#### Scenario: Item length limit

- GIVEN користувач вводить елемент довший за 40 символів
- WHEN він намагається його додати
- THEN ввід обрізається на 40 символах

#### Scenario: Editor has no game mode control

- GIVEN користувач відкриває редактор пресету
- WHEN він переглядає доступні поля
- THEN там є назва та елементи
- AND перемикача вибування немає

### Requirement: Starter Presets

При першому запуску система SHALL створити стартовий набір пресетів. Стартові пресети є **звичайними пресетами**: редагуються, перейменовуються й видаляються нарівні з користувацькими. Прапорця «вбудований» і захисту від редагування не існує.

Набір: Так/Ні · Кубик · Хто перший · Що поїсти · Фільм на вечір · Дні тижня · Кольори. Вміст — `docs/mechanics.md` §10.

Стартові дані MAY задавати початковий режим гри для окремого пресету. Це значення застосовується лише в момент створення стану пресету й далі не має жодної сили.

#### Scenario: First launch

- GIVEN застосунок відкрито вперше й сховище порожнє
- WHEN застосунок ініціалізується
- THEN створено сім стартових пресетів
- AND усі вони доступні для редагування та видалення

#### Scenario: Seeded game mode

- GIVEN пресет «Хто перший» відкривається вперше
- WHEN створюється його стан
- THEN вибування увімкнено
- AND для решти пресетів вибування вимкнено

#### Scenario: Seed does not override later choice

- GIVEN користувач вимкнув вибування для пресету «Хто перший»
- WHEN він перезавантажує застосунок
- THEN вибування лишається вимкненим

#### Scenario: Starter presets are not restored

- GIVEN користувач видалив стартовий пресет
- WHEN він перезавантажує застосунок
- THEN видалений пресет не з'являється знову
