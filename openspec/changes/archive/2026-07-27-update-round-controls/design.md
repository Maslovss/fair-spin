# Design: Round Controls

## Decision: Прапорець переїжджає, а не дублюється

Розглядався варіант лишити в пресеті значення за замовчуванням, а в стані — живе. Відкинуто: два поля для одного поняття неминуче розходяться, і доводиться щоразу вирішувати, яке з них показувати в редакторі.

Оскільки стан персистентний, зручність не втрачається: користувач обирає режим один раз на пресет, далі значення просто лежить. Різниця лише в тому, що тепер його можна перемкнути будь-коли, зокрема посеред раунду.

Початкове значення потрібне лише в момент створення стану. Воно береться зі стартових даних, тому в типі пресету поля не з'являється — це властивість набору стартових пресетів, а не структури пресету.

## Decision: Вимкнення ховає раунд, а не стирає

Скасування кидка ми свідомо не реалізуємо (`docs/mechanics.md` §8), тож у користувача немає способу відкотити випадковий дотик. Стирання цвинтаря при перемиканні режиму було б єдиною незворотною дією без підтвердження.

Реалізація: цвинтар лишається у стані як є, від режиму залежить лише те, чи бере він участь в обчисленні складу столу та чи показується.

```ts
const onTable = elimination
  ? layout.order.filter(id => !drawn.includes(id))
  : layout.order
```

Наслідок, який варто знати: при вимкненому вибуванні на столі знову з'являються ті, хто вже вибув. Це очікувано — режим саме про це.

## Decision: Скидання показується лише коли є що скидати

Кнопка з'являється, коли цвинтар непорожній. Це прибирає безглузду дію на щойно початому раунді й водночас робить сам факт її появи підказкою, що раунд триває.

Підтвердження обов'язкове, бо дія незворотна. Формулювання має називати число: «Скинути раунд? Вибуло 5 із 12.»

## Storage Migration

Версія схеми піднімається до 2.

```ts
function migrateV1toV2(data: StoredV1): StoredV2 {
  // для кожного пресету: перенести elimination у states[preset.id]
  // якщо стану ще немає — створити з єдиним полем elimination
  // видалити поле з пресету
}
```

Стан міг не існувати (лінива розкладка), тому міграція має вміти створити його з одним полем. Решта полів дописуються, як і раніше, при першому дотику до столу.

Тести міграції обов'язкові: пресет зі станом і незавершеним раундом, пресет без стану, дані версії 2 без змін, пошкоджені дані.

## UI Placement

Перемикач розташовується біля перемикача столів у шапці столу, де вже є місце. Два підписані стани поруч, поточний виділений — не чекбокс.

Пропоновані підписи: «Обраний: **Залишається** / **Вибуває**».

Кнопка скидання — поруч із цвинтарем, оскільки саме його вона очищає. Це прив'язує дію до її наслідку візуально.

## Testing

Чиста логіка, без DOM:

- перемикання режиму зберігає цвинтар і повертає його незмінним;
- склад столу відповідає режиму;
- скидання очищає цвинтар, перемішує розкладки, не чіпає кут колеса;
- скидання недоступне на порожньому цвинтарі;
- міграція у чотирьох сценаріях вище.
