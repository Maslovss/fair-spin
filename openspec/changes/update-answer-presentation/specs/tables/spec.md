# Delta for Tables

## ADDED Requirements

### Requirement: Answer Is Shown With Its Question

Відповідь SHALL показуватись разом із поставленим запитанням як єдиний блок біля столу.

Запитання подається другорядним, відповідь — головною: питання вже відоме, нова саме відповідь.

Показане на екрані MUST збігатися з парою, яка йде в поширення. Користувач не має надсилати те, чого не бачив.

Повтор запитання в блоці є навмисним: заголовок сторінки й блок відповіді розділені столом, і на телефоні одночасно не видно обох.

#### Scenario: Question and answer form one block

- GIVEN поставлено запитання «Як думає про мене чувак?» і отримано відповідь
- WHEN користувач дивиться під стіл
- THEN запитання й відповідь показані разом
- AND запитання подано другорядним, відповідь — головною

#### Scenario: Template question shows its posed form

- GIVEN шаблон «Коли…?» доповнено текстом «поїхати до бабусі»
- WHEN показано відповідь
- THEN у блоці стоїть «Коли поїхати до бабусі?»
- AND назва «Коли…?» не показується

#### Scenario: Screen matches what is shared

- GIVEN показано блок відповіді
- WHEN користувач ділиться відповіддю
- THEN запитання й відповідь у тексті збігаються з показаними на екрані

## MODIFIED Requirements

### Requirement: Result Label Reflects Current Table State

Блок відповіді SHALL показувати відповідь останньої завершеної дії на **поточному** столі разом із поставленим запитанням.

В інтерфейсі та в текстах поширення вживається слово **«відповідь»**. Слово «результат» лишилось від часів, коли застосунок був рандомайзером, і MUST NOT з'являтися в підписах.

Блок MUST зникати повністю, коли стіл повертається до стану, у якому відповіді ще немає:

- при перемиканні на інший стіл;
- при відкритті запитання;
- після скидання раунду;
- після постановки нового запитання;
- після перемикання режиму гри;
- після збирання колоди на столі карт;
- після перезавантаження застосунку.

Блок MUST NOT зберігатися між сесіями й MUST NOT показувати відповідь, отриману на іншому столі.

#### Scenario: Switching tables clears the answer

- GIVEN на колесі показано відповідь
- WHEN користувач перемикається на інший стіл
- THEN блоку відповіді немає

#### Scenario: Undealt deck shows no answer

- GIVEN на столі карт колоду зібрано й ще не роздано
- WHEN користувач дивиться на стіл
- THEN блоку відповіді немає

#### Scenario: Answer persists while the table is unchanged

- GIVEN користувач зробив кидок на колесі
- WHEN такт визнання завершився і гравець лишається на колесі
- THEN блок показує саме цю відповідь

#### Scenario: Reset clears the answer

- GIVEN показано відповідь
- WHEN користувач скидає раунд або ставить нове запитання
- THEN блоку відповіді немає

#### Scenario: Mode change clears the answer

- GIVEN показано відповідь
- WHEN користувач перемикає режим гри
- THEN блоку відповіді немає

#### Scenario: Answer is not restored after reload

- GIVEN користувач отримав відповідь і перезавантажив застосунок
- WHEN запитання відкривається знову
- THEN блоку відповіді немає
- AND порядок лишається незмінним

#### Scenario: Final act answer matches the table

- GIVEN у раунді лишився один елемент
- WHEN користувач обирає його
- THEN блок показує саме цей елемент як відповідь
