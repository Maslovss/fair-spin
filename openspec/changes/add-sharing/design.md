# Design: Sharing

## Encoding

```
{ n: name, i: [items] }
  → JSON
  → TextEncoder
  → CompressionStream('deflate-raw')
  → base64url
  → '#q=1.' + payload
```

**Позначка версії** — цифра перед крапкою. Дозволяє відхилити майбутній формат, не розпаковуючи.

**`TextEncoder` обов'язковий.** `btoa` на рядку з кирилицею чи емодзі падає. Це найімовірніше місце помилки в усій зміні, бо на латиниці все працюватиме.

**`CompressionStream` може бути відсутнім** у старих рушіях. Відкат — та сама послідовність без стиснення, з іншою позначкою версії, щоб розбір знав, чого очікувати. Стиснення дає приблизно триразовий виграш на списках імен, тож перевіряти межу довжини треба вже після нього.

**Ключі короткі** (`n`, `i`) навмисно: у стиснутому вигляді різниця невелика, але у відкаті без стиснення — помітна.

**Форму не кодуємо.** Шаблон і завершене запитання розрізняються трикрапкою в назві, тож окремої ознаки в посиланні не потрібно.

## Limits

```ts
MAX_LINK_CHARS = 2000   // включно з базовою адресою
MAX_ITEMS      = 1000   // як у редакторі
MAX_ITEM_LEN   = 40     // як у редакторі
MAX_NAME_LEN   = 60
```

Межі імпорту MUST збігатися з межами редактора. Розбіжність дасть запитання, які не можна відредагувати.

## Import Pipeline

```
hash → версія → base64url → розпакування → JSON → валідація → перегляд → рішення → replaceState
```

Валідація відкидає: перевищення меж, керуючі символи, порожні елементи після обрізання пробілів, менше двох елементів.

`history.replaceState` очищає хеш після рішення — інакше оновлення сторінки пропонує імпорт удруге.

Помилка на будь-якому кроці не має валити застосунок: повідомлення й звичайний запуск.

## Conflict Detection

Порівняння **за назвою**, точний збіг після обрізання пробілів. Ідентифікатори в посилання не кладемо: інакше чуже посилання могло б переписати наявне запитання без відома власника.

Збіг елементів — порівняння як мультимножин у порядку списку. Дублікати значущі, бо вони є вагами.

Різниця показується як `+N −M` зі списком доданих і зниклих. Два повні списки поруч на телефоні не вміщаються.

Назви унікальні, тому копію поруч створити не можна: лишаються заміна або скасування. Для збереження обох користувач спершу перейменовує наявне запитання.

## Message Templates

Заголовок — **поставлене запитання**. Пара запитання-відповідь береться з тієї самої функції, що формує блок на екрані.

**Одна відповідь**

```
🎲 {question}
{item}

{table} · Fair Spin — {url}
```

Приклад:

```
🎲 Коли поїхати до бабусі?
⏳ Згодом

Колесо · Fair Spin — maslovss.github.io/fair-spin
```

**Порядок, раунд завершено**

```
🎲 {question}
{order_label} ({all_label} {n}):
1. {item}
…

Fair Spin — {url}
```

**Порядок, раунд триває**

```
🎲 {question}
{order_label} ({n} {of_label} {total}):
1. {item}
…

Fair Spin — {url}
```

**Обрізання**

```
1. {item}
…
20. {item}
…{and_more_label} {rest}
```

Числа не конфліктують: `60 з 81` — скільки записів у порядку, `і ще 40` — скільки з них не показано.

Межа обрізання — за кількістю символів, не рядків, бо елементи різної довжини.

**Стіл згадується лише в тексті однієї відповіді.** У порядку його немає: раунд може проходити через кілька столів, і одна назва була б неправдою.

**Підпису «Відповідь:» немає.** Як і на екрані, роль передається розташуванням: запитання зверху, відповідь під ним.

## Wording Rules

Українська не дає писати минулим часом однини: «крутив» чи «крутила» невідомо, «випав» чи «випала» теж. Тому такі форми виключені, лишається двокрапка й називний відмінок.

Заборонені й оцінювальні слова. Це те саме правило, і воно потребує коментаря у файлах локалізації: наступний перекладач або наступна модель обов'язково спробує зробити текст «живішим», а живіше тут означає хибне.

Словник збігається з інтерфейсним: Запитання, Відповідь, Порядок. Слова «результат» немає ніде.

## Share Mechanism

```ts
if (navigator.share) await navigator.share({ text })
else await navigator.clipboard.writeText(text)
```

Обидва шляхи потребують дії користувача. `navigator.share` — системний лист операційної системи, мережевим запитом застосунку не є, отже заборона мережі не порушується.

Для посилання на запитання передаємо `text` із готовим рядком, а не `url`: частина застосунків обрізає хеш у полі `url`.

## Testing

Чиста логіка, без DOM:

- кодування й розбір із кирилицею та емодзі;
- відкат без стиснення дає той самий результат після розбору;
- невідома версія відхиляється без розпакування;
- пошкоджені дані відхиляються без винятків назовні;
- межі імпорту збігаються з межами редактора;
- шаблон лишається шаблоном після подорожі посиланням;
- виявлення конфлікту: збіг, розбіжність, дублікати як ваги;
- шаблони тексту для чотирьох випадків, включно з обрізанням;
- стіл згадується в одній відповіді й не згадується в порядку;
- пара в тексті збігається з парою на екрані;
- у сформованому тексті немає заборонених слів і слова «результат».
