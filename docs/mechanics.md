# Fair Spin — механіка v1

> Слоган: **«Ніхто не знає наперед. Навіть застосунок.»**

Документ описує **тільки механіку**. Реалізація, стек, UI-верстка — поза межами.

---

## 0. Принцип

**Чесний Стіл.**

- Усе, що лежить на столі, реально може випасти.
- Усе, що випасти не може, зі столу зникає.
- Гравець — учасник, а не глядач.

Принцип працює як лінійка: будь-яка нова фіча перевіряється питанням «це чесний стіл?».

---

## 1. Інваріанти

Перевіряються як тести. Порушення жодного не допускається.

| # | Інваріант |
|---|---|
| **І1** | Результат не існує, доки предмет фізично не зупинився. Переможець не обчислюється наперед. |
| **І2** | Кожен результат ініційований явною дією гравця. Ніщо не стартує саме. |
| **І3** | На столі присутні лише ті елементи, які реально можуть випасти. |
| **І4** | Розкладка стабільна всередині раунду (крім вилучення вибулих). |
| **І5** | Промах можливий: жест нижче порога = нічого не сталося. |
| **І6** | Результат не перекриває екран. Немає модального вікна «Переможець!». |
| **І7** | Мінімальний зарахований кидок дає щонайменше 2–3 повних оберти. |

**«Спробувати удачу»** інваріантам не суперечить: це явна дія гравця (І2), яка запускає ту саму фізику з випадковою силою. Гравець свідомо знімає з себе відповідальність за кидок. Позначок у цвинтарі не лишає.

## 2. Сутності

Рівно три. Більше немає нічого.

### 2.1 Пресет

```
Preset:
  id
  name                 — назва
  items[]              — рядки (текст + unicode-емодзі), мінімум 2
  elimination: bool    — прибирати обраного зі столу
  createdAt, updatedAt
```

- **Дублікати дозволені й нічого не питаємо.** Дублікат = вага. Окремого поля ваги не існує.
- Ліміт довжини елемента: **40 символів**.
- Мінімум **2 елементи** — валідація при збереженні.
- Емодзі — частина тексту, окремих полів кольору/іконки немає.

### 2.2 Стан пресету

Існує завжди, один на пресет. Не має терміну придатності.

```
State(presetId):
  lastTable            — 'wheel' | 'reel' | 'cards'
  drawn[]              — вибулі, у порядку випадання (лише при elimination)
  tables:
    wheel: { order[], angle }
    reel:  { order[], offset }
    cards: { order[], dealt: bool, cut: bool }
  updatedAt
```

- Розкладка конкретного столу створюється **ліниво** — коли гравець уперше взяв цей предмет.
- **Кожен стіл має власний `order[]`.** Зріз колоди не провертає колесо.
- **`angle` колеса переживає все**, включно з новим раундом і закриттям браузера. Справжнє колесо не телепортується в нуль.
- Коли `elimination = false`, `drawn[]` завжди порожній і банер продовження не показується.

### 2.3 Налаштування

```
Settings:
  sound: bool
  haptics: bool
  lang: 'uk' | 'en'
```

## 3. Життєвий цикл раунду

Застосовний лише при `elimination = true`.

```
        ┌──────────────┐
        │  Новий раунд │  order[] усіх столів тасуються заново
        └──────┬───────┘  drawn[] = []   |   angle НЕ скидається
               │          cards.dealt = false, cards.cut = false
               ▼
        ┌──────────────┐
   ┌───▶│  Гра         │  стіл: N живих елементів
   │    └──────┬───────┘
   │           │ гравець діє → фізика → зупинка
   │           ▼
   │    ┌──────────────┐
   │    │  Результат   │  підсвітка → з'їжджає в цвинтар
   │    └──────┬───────┘
   │           │
   └───────────┤ лишилось > 1
               │
               ▼ лишився 1
        ┌──────────────┐
        │  Фінальний   │  без кидка: гравець тапає єдиний об'єкт
        │  акт         │
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │  Раунд       │  стіл порожній, цвинтар повний
        │  завершено   │  [Новий раунд] [Скопіювати порядок]
        └──────────────┘
```

**Банер продовження** при відкритті пресету з непорожнім `drawn[]`:

> Раунд у процесі: 4 з 12, останнє — вчора
> **Продовжити** · **Новий раунд**

«Новий раунд» стирає попередній — тільки з підтвердженням.

**Цвинтар** — постійно на екрані збоку, нумерований, у порядку випадання. Це і є історія; окремого логу результатів не існує. Має кнопку **«Скопіювати порядок»**.

## 4. Контракт столу

Будь-який стіл, теперішній чи майбутній, зобов'язаний мати три такти.

| Такт | Що відбувається |
|---|---|
| **1. Спокій** | Нічого не рухається. Видима фізична зачіпка. Через ~3 с бездіяльності — тонка підказка-привид. |
| **2. Ввід** | Об'єкт слухається пальця 1:1, поки гравець тримає. Можна передумати. До відпускання нічого не вирішено. |
| **3. Розв'язка** | Інерція, тертя, тики, сповільнення, зупинка з легким відкатом. |

Стіл без такту 2 не є столом і в застосунок не приймається.

**Фізичність продається трьома каналами**, у порядку важливості:
1. Вібрація на кожен тик (кілочок, клац, шурхіт).
2. Звук, частота якого прив'язана до швидкості.
3. Живий відгук під час жесту (опір, запізнення, відкат).

Невдалий жест теж має відгук: колесо хитнулось і зітхнуло. Це вчить силі без інструкцій.

## 5. Столи

### 5.1 Колесо — `wheel`

- **Жест:** хапаєш за обід, ривок. Швидкість відпускання = сила.
- **Межі:** 2–30 елементів.
- **Стан:** `order[]` (тасується на новому раунді), `angle` (зберігається завжди).
- Язичок стукає по кілочках: тик + вібрація на кожен.
- Вибулий зникає, сектори з'їжджаються анімацією.
- Стартова позиція щоразу інша — там, де лишив попередній кидок.
- **Текст:** до 16 секторів — назва вздовж радіуса всередині сектора; 17–30 — номер у секторі плюс легенда збоку.

### 5.2 Рушій котушки — `reel`

Один рушій, кілька виглядів. **Жест належить вигляду, не рушію.**

| Вигляд | Жест |
|---|---|
| Слот-машина | тягнеш ричаг, він опирається пружиною; треба перетягнути поріг, інакше зіскочить ні з чим |
| Стрічка | флік убік, швидкість змаху = дальність |

- **Один барабан.** Три барабани відкинуті: результат читав би лише центральний, тобто два з трьох тапів ні на що не впливають — театр.
- Тап під час крутіння = різке гальмо. Обидва жести справжні.
- **Межі:** 2–500+.
- **Стан спільний для всіх виглядів:** `order[]`, `offset`. Перемкнув слот на стрічку — котушка та сама.
- Нові вигляди додаються без зміни рушія.

### 5.3 Карти — `cards`

- **Межі:** 2–16 елементів. Більше на телефоні означає або мікроскопічні карти, або скрол — а скрол убиває відчуття стола перед тобою.
- **Дефолт:** `elimination = true`.

**Цикл із вибуванням:**
```
тасування (рандом) → зріз (гравець, ≥1 раз) → «Роздати» →
тап по карті → реваль → у цвинтар → тап по наступній → ...
```

**Цикл без вибування** (карта повертається в колоду):
```
тасування → зріз → «Роздати» → тап → реваль →
колода збирається → тасування → зріз → «Роздати» → ...
```

- **Зріз:** тягнеш палець по колоді, обираєш місце, верхня частина відходить, нижня стає зверху. Скільки завгодно разів.
- Після «Роздати» карти **не рухаються до кінця раунду**. Позиції зафіксовані.
- Вибула карта йде в цвинтар, решта лишаються на своїх місцях — хід раунду видно прямо на столі.
- Без вибування зріз обов'язковий **щоразу** — інакше тасування рандомне й дія гравця зникає.

## 6. Матриця доступності

| Розмір столу | wheel | reel | cards |
|---|:---:|:---:|:---:|
| 2–16 | ✅ | ✅ | ✅ |
| 17–30 | ✅ | ✅ | — |
| 31+ | — | ✅ | — |

**Правила:**
- Недоступний стіл **не показується** у виборі. Не «показується і криво малює».
- При вибуванні список тане → стіл може **стати доступним посеред раунду**. З'являється тихо в списку, без сповіщень.
- Зворотного не буває: стіл не зникає посеред раунду, бо стіл лише зменшується.
- Перемикати стіл можна **посеред раунду**. Стіл належить раунду, а не навпаки: цвинтар той самий, розкладка нового столу створюється ліниво.
- Якщо `lastTable` недоступний за розміром — тихий фолбек на `reel`.

## 7. Крайні випадки

| Ситуація | Поведінка |
|---|---|
| Елемент **додано** до пресету посеред раунду | З'являється на столі у випадковій позиції. Мовчки. |
| Елемент **видалено** посеред раунду | Зникає зі столу або з цвинтаря. Мовчки, без діалогів і повідомлень. |
| Раунд скорочується до 1 | Фінальний акт: тап без кидка. |
| Пресет із 1 елемента | Заборонено валідацією. Механічно працює, але це кнопка, а не рандомайзер. |
| Жест нижче порога | Об'єкт хитнувся, повернувся. Нічого не сталося, результату немає. |
| Жест надмірної сили | Обмежується стелею ~12–15 обертів. |
| Раунд лежить місяцями | Живе. Терміну придатності немає. |
| `prefers-reduced-motion` | «Спробувати удачу» доступна як звичайна дія. Анімація скорочується. |

## 8. Свідомо поза v1

| Відкинуто | Причина |
|---|---|
| Cooldown / «проскакує» | Порушує чесний стіл: об'єкт на столі, але випасти не може. |
| Сірі сектори вибулих | Те саме — стрілка «магічно» проїжджає. |
| Плінко | Біноміальний розподіл: центр вигідніший за край. Нечесний за побудовою. |
| Crystal Ball | Немає такту 2 — гравець не бере участі. |
| Ball Machine | Дублює карти механічно. |
| Три барабани зі skill stop | Два з трьох тапів нічого не вирішують. |
| Режим «Гальмо» | Гра на реакцію, а не рандом. |
| Ваги окремим полем | Замінені дублікатами. |
| Тимчасове вимкнення елемента | Дрібниця: захворів — крутнув ще раз. |
| Undo кидка | Переспін = порушення чесності. Захист від випадковості дає поріг сили. |
| Історія 100 результатів | Цвинтар і є історією. |
| Статистика, гістограми | Доказ чесності вбудований у механіку. |
| Ачівки, розблокування | Overkill. |
| Мультивибір N однією дією | Робиться руками: N кидків з вибуванням. |
| Команди на K груп | v2. |
| Параметричні пресети (1–100) | Пишеться руками: 1, 2, 3… |
| Спільний синхронний розіграш на кількох пристроях | Потребує сервера й узгодження єдиного стану раунду; посилання переносить лише запитання. |
| Підтверджена іншими учасниками відповідь | Локальний застосунок не може довести, що поширений текст відповідає реальному ходу. |
| Синхронізація запитань між пристроями | Потребує облікового запису або бекенду; у v1 запитання передається явним посиланням. |
| Реплей кидка посиланням | Відтворення фізики залежить від версії рушія й створювало б лише ілюзію тотожного кидка. |
| Пресет фізики (важке / легке колесо) | Overkill. Фізика одна, підібрана добре. |
| Російська мова | Не буде до закінчення війни. |

## 9. Зафіксовано додатково

- **Назва** — Fair Spin. Без «Wheel»: карти не крутяться, а назва має пережити появу нових столів.
- **Перший запуск** — колесо. Так усі звикли. Далі кожен пресет пам'ятає свій останній стіл.
- **PWA** — так. Іконка на телефоні, офлайн.
- **Мови** — українська, англійська.

## 10. Стартові пресети

Створюються при першому запуску як **звичайні пресети**: редагуються, перейменовуються, видаляються нарівні з користувацькими. Прапорця `builtin`, захисту від редагування і логіки «зберегти як копію» немає — одна сутність, нуль спецвипадків.

| Пресет | Елементи | Вибування |
|---|---|:---:|
| Так / Ні | ✅ Так · ❌ Ні | ні |
| Кубик | ⚀ 1 · ⚁ 2 · ⚂ 3 · ⚃ 4 · ⚄ 5 · ⚅ 6 | ні |
| Хто перший | Гравець 1 … Гравець 4 | **так** |
| Що поїсти | 🍕 Піца · 🍜 Локшина · 🥟 Вареники · 🍲 Суп · 🍝 Паста · 🥪 Бутерброд · 🍳 Яєчня | ні |
| Фільм на вечір | 🎬 Комедія · 👽 Фантастика · 🦸 Супергерої · 🐉 Аніме · 🕵️ Детектив · 🏰 Пригоди · 😱 Жахи | ні |
| Дні тижня | Понеділок … Неділя | ні |
| Кольори | 🟥 Червоний · 🟧 Помаранчевий · 🟨 Жовтий · 🟩 Зелений · 🟦 Синій · 🟪 Фіолетовий · 🟫 Коричневий · ⬛ Чорний · ⬜ Білий | ні |

Два пресети несуть навчальну функцію понад свій прямий зміст:

- **Кольори** — демонстрація того, що емодзі є частиною тексту. Дитина бачить кольорові квадрати в назвах і сама розуміє, що так можна робити у власних списках.
- **Хто перший** — єдиний стартовий із вибуванням. Показує механіку черги та цвинтаря без жодного пояснення.
