# Fair Spin

**Ніхто не знає наперед. Навіть застосунок.**

Веб-застосунок, який допомагає обрати, коли обрати важко. Крутиш колесо, тягнеш ричаг, зрізаєш колоду — і отримуєш відповідь.

👉 **[maslovss.github.io/fair-spin](https://maslovss.github.io/fair-spin/)**

## Ідея

Майже всі рандомайзери влаштовані однаково: програма обирає відповідь, а потім показує гарну анімацію, яка «доїжджає» до вже відомого результату. Ти натискаєш кнопку й дивишся ролик.

Тут навпаки.

Ти хапаєш колесо за обід і робиш ривок. Сила ривка визначає, скільки обертів воно пройде і де зупиниться. Відповідь — це те, куди воно доїхало. **До зупинки її не знає ніхто, включно із застосунком.**

Головне правило називається **Чесний Стіл**:

- усе, що лежить на столі, реально може випасти;
- усе, що випасти не може, зі столу зникає;
- гравець — учасник, а не глядач.

Саме тому тут немає сірих секторів, крізь які стрілка «магічно» проїжджає, немає гальма, яким можна підгадати момент, і немає можливості перекрутити невдалу відповідь.

## Чотири столи

| Стіл | Жест | Скільки варіантів |
|---|---|---|
| 🎡 **Колесо** | ривок за обід | 2–30 |
| 🎰 **Слот** | тягнеш ричаг | від 2 |
| 🎞 **Стрічка** | змах убік | від 2 |
| 🃏 **Карти** | зрізаєш колоду й обираєш карту | 2–16 |

Столи можна перемикати посеред гри — стіл змінюється, а хід раунду лишається.

Якщо крутити не хочеться або незручно, є кнопка **«Спробувати удачу»**: та сама фізика, тільки силу обирає застосунок. Це усвідомлений вибір делегувати кидок, а не запасний варіант для тих, хто не впорався.

## Запитання

Усе в застосунку — запитання. Їх дві форми.

**Готові запитання** мають свій список і крутяться одразу:

> **Що подивитись?** → 🎬 Комедія · 👽 Фантастика · 🐉 Аніме…

**Шаблони** мають трикрапку в назві. Перед розіграшем ти доповнюєш їх своїм текстом:

> **Коли…?** + «поїхати до бабусі» → **Коли поїхати до бабусі?**
> Відповідь: ⏳ Згодом

Шаблони зі шкалами відповідають на питання, де ти знаєш, **що** питаєш, але не знаєш, **які бувають відповіді**: скільки, коли, наскільки добре, чи взагалі станеться.

У наборі з коробки: `Так чи ні…?` · `Треба чи ні…?` · `Хто…?` · `Скільки…?` · `Як…?` · `Коли…?` · `Чи станеться…?` · `Наскільки важливо…?` · `Якого кольору…?` · `Якого дня…?`

Свій шаблон робиться просто: постав трикрапку в назві будь-якого запитання.

Якщо питання надто особисте, щоб його друкувати — залиш поле порожнім. Підставиться `‹задумане›`, і що саме ти загадав, лишиться при тобі.

## Два режими

Перемикач біля столу:

- **Залишається** — усі варіанти щоразу на місці. Для запитань, які ставлять багато разів.
- **Вибуває** — обраний іде зі столу в «Порядок». Так виходить черга: хто перший, хто другий, хто останній.

Раунд із вибуванням живе скільки завгодно: можна закрити застосунок і продовжити через тиждень з того самого місця.

## Поставити на телефон

Застосунок ставиться як звичайна програма — з іконкою й без адресного рядка. Працює **повністю офлайн**.

**Android:** відкрий [посилання](https://maslovss.github.io/fair-spin/) у Chrome → меню ⋮ → **Встановити застосунок**.

**iPhone:** відкрий у Safari → **Поділитися** → **На екран «Домів»**.

Тактильний відгук на кожен кілочок працює на Android; на iPhone лишаються звук і анімація — це обмеження браузера, а не застосунку.

## Поділитися

Дві різні дії, і різниця між ними важлива.

**Поділитися запитанням** — надсилаєш посилання, друг отримує копію списку й крутить своє. Довіри не потребує: кожен бачить свій кидок на власному телефоні.

**Поділитися відповіддю** — надсилаєш текст:

```
🎲 Хто миє посуд?
Порядок (усі 3):
1. Петро
2. Андрій
3. Наталка
```

Це просто повідомлення про те, що сталося. Застосунок гарантує чесність кидка тому, хто крутив, але чесність переказу гарантувати не може — це вже питання довіри між друзями, і вдавати інше було б брехнею.

Якщо потрібна одна відповідь на всіх — крутіть на одному телефоні поруч. Так робили з лічилками задовго до застосунків.

## Приватність

- Немає сервера. Немає акаунтів. Немає реєстрації.
- Немає аналітики, лічильників і реклами.
- Жодного мережевого запиту під час роботи.
- Усі запитання та раунди лежать у твоєму браузері й нікуди не йдуть.

Саме тому тут немає банера про куки: збирати нічого.

## Мови

Українська та англійська, перемикається в налаштуваннях. Інтерфейс перекладається, **твої тексти — ніколи**: якщо ти написав «Петро», він не стане «Petro».

## Технічно

TypeScript, Vite, без UI-фреймворка. Колесо — SVG, решта — DOM і CSS. Звук синтезується через Web Audio, аудіофайлів немає. Дані — `localStorage`. Офлайн — PWA. Жодної залежності в рантаймі.

```bash
npm install
npm run dev        # локальний сервер
npm run test       # тести
npm run build      # збірка
```

Проєкт розробляється **специфікаціями наперед** через [OpenSpec](https://github.com/Fission-AI/OpenSpec): спершу описується поведінка, потім пишеться код.

- [`docs/mechanics.md`](docs/mechanics.md) — механіка й інваріанти. У §8 лежить список **відкинутих ідей із причинами** — там видно, чому в застосунку немає скасування кидка, історії результатів і статистики.
- [`docs/starter-presets.md`](docs/starter-presets.md) — вміст стартового набору обома мовами.
- [`openspec/specs/`](openspec/specs/) — чинні специфікації поведінки.
